# 📝 To-Do List Web Application

A responsive and interactive To-Do List application developed using HTML, CSS, and JavaScript as part of my Web Development Internship at RaushByte Technologies.

## 🚀 Features

- Add new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Mark tasks as completed
- Set task priorities (High, Medium, Low)
- Set optional due dates and times
- Filter tasks by All, Pending, and Completed
- Track task completion progress
- Display total and completed task counts
- Clear all completed tasks
- Save tasks using Browser Local Storage
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 💻 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Start managing your tasks!
